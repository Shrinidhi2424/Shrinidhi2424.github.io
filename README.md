# Shrinidhi Shetty: portfolio

Single-page developer portfolio (React 19, Vite, TypeScript), deployed to https://shrinidhi2424.github.io.

The build plan lives in [PORTFOLIO_PLAN.md](PORTFOLIO_PLAN.md).

## Run

    npm install
    npm run dev       # http://localhost:5173
    npm run build
    npm run preview
